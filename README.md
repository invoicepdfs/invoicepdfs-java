# invoicepdfs-java

Official java client for the [InvoicePDFs](https://invoicepdfs.com) API,
generated from [invoicepdfs-openapi](https://github.com/invoicepdfs/invoicepdfs-openapi).

> Client code is generated by CI. Run the **Generate SDK** workflow (Actions tab),
> or it regenerates automatically when the spec changes.

## Install (after first release)
```
Maven: com.invoicepdfs:invoicepdfs
```
